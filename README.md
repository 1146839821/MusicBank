# MusicBank · 乐测题库

MusicBank 是面向小学音乐教师和教研员的本地题库与练习应用。当前版本包含 Vue 3 + TypeScript 渲染层，以及 Electron + SQLite 桌面数据层基础。

## 开发

```bash
npm install
npm run dev
```

浏览器开发模式使用 `localStorage` 作为回退存储。浏览器内可以录入题目、插入图片和 MP3/WAV 预览，并打开五线谱/简谱谱面编辑器；完成后谱面会导出为题目图片。

## 桌面端

```bash
npm run build
npm run start
```

桌面端数据写入 Electron `userData/data/`：

- `database/music_questions.db`：SQLite 数据库，启用 WAL 和外键。
- `assets/audio/`：音频素材。
- `assets/images/`：图片素材。

渲染层只能通过 Preload 暴露的白名单接口访问题目、试卷、考试、练习记录和素材。导入题目的图片与音频会复制到上述应用数据目录，题目只保存资源 ID，不依赖用户原始文件路径；页面通过 `musicbank-asset://<assetId>` 协议读取素材，因此重启应用后仍可预览。考试开始、逐题作答和交卷会写入 SQLite；练习结果与错题会去重保存，重启桌面应用后可以恢复错题列表。音频第一次读取元数据后，真实时长也会回写到素材表。试卷管理可以浏览已保存的快照、载入配置、直接开始模拟考试或删除本地试卷。

系统页的“数据备份”会导出单个 `.musicbank.json` 文件，其中包含题目、试卷快照、错题关联、Word 试卷模板以及应用数据目录中的图片和音频字节；恢复备份前会提示替换当前本地数据，并清理旧素材文件。

## 检查

```bash
npm run build
npm test
```

`npm run dist` 使用 electron-builder 生成 macOS DMG 和 Windows NSIS 配置对应的安装包。正式分发前仍需在目标系统准备 Electron 二进制、原生模块和代码签名环境。

## GitHub Actions 发布

`.github/workflows/build-desktop.yml` 会在手动触发或推送 `v*` 版本标签时并行构建三个桌面版本：

- `MusicBank-<version>-x64.dmg`：macOS Intel
- `MusicBank-<version>-arm64.dmg`：macOS Apple silicon
- `MusicBank-Setup-<version>-x64.exe`：Windows x64

Windows 使用 NSIS 安装程序，支持选择安装目录、桌面和开始菜单快捷方式，并在系统“应用和功能”中提供 MusicBank 卸载入口。卸载默认保留应用数据目录，避免误删题库；如需清理数据，请在应用内使用备份和数据管理功能。

创建并推送版本标签后，工作流会把三个安装包和对应的 blockmap 文件发布到 GitHub Release：

```bash
git tag v0.1.0
git push origin v0.1.0
```

## 音乐符号

录题时可以打开“谱面编辑器”，在简谱和五线谱之间切换。五线谱覆盖全音符、二分、四分、八分、十六分、三十二分和六十四分音符，以及对应的附点/复附点时值、休止符、连音、三连音、拍号、升降还原记号、单/双小节线、终止线和反复记号；简谱提供 1–7 与 0、上下加点、下单线、下双线、附点、连音、三连音、分拍线、单/双竖线、终止线和反复线。选择音级后再点加点或下线按钮，会组合成例如 `4̳̇` 的复合记号。完成后点击“生成题目图片”，系统将 PNG 保存到应用数据目录，并通过资源 ID 关联到当前题目。

## 判断题与模板组卷

题库支持选择题（单选/多选）、填空题、判断题和简答题。判断题使用“正确 / 错误”录入标准答案，在练习、模拟考试中自动评分；简答题保留人工阅卷。

1. 在“试卷模板”上传学校的 `.docx` 空白模板（最多 15MB）。模板正文使用“一、填空题”“二、选择题”“三、判断题”“四、简答题”等独立段落标题，也可以使用单独一段 `{{试题}}` 作为插入位置。两种方式选择其一。
2. 在“生成试卷”选择模板，填写学校、学年、学期、年级、考试日期、时长和说明，设置每种题型的数量与每题分值。题库不足或总分不匹配时会提示调整。
3. 生成并保存试卷快照，打开“预览与导出”，分别选择“学生试卷”“参考答案”，下载各自的 Word 或 PDF。桌面版可以直接打开系统打印窗口。
4. 桌面版点击“连同音频打包 ZIP”，选择保存位置，一次导出 `试题.docx`、`参考答案.docx`、`试题.pdf`、`参考答案.pdf`、`audio/` 原始音频、`音频清单.json` 和使用说明。清单中的 `audioNumber` 与试卷的听音材料编号一致；多个题目引用同一素材时，音频文件只打包一份。Word/PDF 本身不包含可播放音频。素材缺失或不完整时会提示错误，不生成缺少音频的资源包。

模板保留纸张、页边距、标题、页眉页脚与题型顺序；题型标题间的示例内容、正文“参考答案”及之后的示例答案会被重新生成。支持跨 Word 文本片段的占位符：`{{试卷名称}}`、`{{学校}}`、`{{学年}}`、`{{学期}}`、`{{学科}}`、`{{年级}}`、`{{考试日期}}`、`{{考试时长}}`、`{{总分}}`、`{{考试说明}}`。题型标题需位于正文独立段落，不支持表格内的题型区域。

模板内容存入应用 SQLite 数据库，不依赖原文件路径。移除模板后不再用于新组卷，已保存试卷仍可导出。浏览器开发模式通过 IndexedDB 保存模板，PDF 使用浏览器打印另存；正式桌面版提供原生下载入口。图片会嵌入 Word，听音题标注播放材料，由教师统一播放。打印预览使用本机字体，复杂浮动文本框应同时核对 Word 原稿；班级、姓名、得分标准浮动字段会转换为可打印的信息行。

谱面按拍号与时值自动显示小节线，校验附点、三连音、休止符及各独立声部的拍数。未满与超拍小节会在编辑器提示；弱起和教学片段可保留，跨小节的长音请拆成音符后添加延音线。自动小节线随导出图片显示，不改变源稿中的音符或手动反复线、终止线。
